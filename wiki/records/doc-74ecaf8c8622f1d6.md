# 知识模块40：截图与录屏

ID: `doc-74ecaf8c8622f1d6` · 类型：历史来源 · 审核：`machine_reviewed`

本知识模块讲解截图与录屏工具的使用，要求参赛者掌握 QQ 的截图、贴图、录屏等功能，并能够熟练使用软件 LICEcap 把屏幕操作录制成 GIF 动图。资料提示，QQ 的截图、录屏功能配有快捷键，截图后出现的工具条上每个按钮都应动手了解其具体功能；LICEcap 则用于将一段屏幕操作录制为可循环播放的 GIF 动图。备赛建议鼓励用 LICEcap 录制屏幕操作，再把生成的 GIF 动图插入 PPT 中播放查看效果，从而熟悉两类工具在日常学习与参赛中的实际应用。

## 操作与核对

1. 使用 QQ 的截图功能并熟悉截图后工具条上每个按钮的具体功能（含图钉状贴图图标）。
2. 使用软件 LICEcap 将一段屏幕操作录制为 GIF 动图。
3. 将 LICEcap 录制的 GIF 动图插入 PPT 中播放，查看其呈现效果。
