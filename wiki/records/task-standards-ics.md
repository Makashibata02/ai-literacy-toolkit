# 标准查询：名称、标准号与 ICS CCS 分类

ID: `task-standards-ics` · 类型：操作卡 · 审核：`machine_reviewed`

确认题目指定国家、行业或地方标准，以及名称关键词和标准状态。；打开官方标准检索，输入名称或标准号，设置页面提供的限定条件。

官方入口：[https://std.samr.gov.cn/gb/search/gbAdvancedSearch](https://std.samr.gov.cn/gb/search/gbAdvancedSearch)

## 输入条件

从题干提取平台、对象、字段、时间、类型、排序指标及需要比较的选项文字。

## 操作与核对

1. 确认题目指定国家、行业或地方标准，以及名称关键词和标准状态。
2. 打开官方标准检索，输入名称或标准号，设置页面提供的限定条件。
3. 查看命中标准的详情或结果记录中的 ICS 和 CCS，逐条记录。
4. 比较题目选项；确认是在问 ICS 还是 CCS，并核对有效状态和查询日期。

- ICS 与 CCS 是两套分类，不互相替代；一个检索词可能命中多项标准。
