# 豆包marscode写词频统计代码

ID: `vid-ddd1793443f03f4b` · 类型：历史来源 · 审核：`machine_reviewed`

本视频演示用豆包 Mars Code（字节跳动 AI 编程工具）写词频统计代码。它是云端 IDE 也可作插件，登录网址即在线编程，自然语言生成代码。英文词频：建 Python 项目，提示词统计词频、显示前 10 并降序，Add File 后 Run 输入文本即得结果。中文词频：因需先分词，报错缺模块时借 AI Fix 得知装 jieba，终端 pip install 结巴后重运行。该工具还能针对调试问题给出方案。

## 操作与核对

1. 访问豆包 Mars Code 工作平台网址并登录，点击“Mars Code IDE → 打开网页/立即体验”，选择 Python 创建项目并命名。
2. 在右侧对话框输入提示词：让程序提示用户输入一段英文文本，统计词频，显示排名前 10 的单词及词频、从高到低排序。
3. 点击代码右上角“Add File”把生成的代码放入工作区，再点击“Run”运行，按提示输入英文文本得到统计结果。
4. 做中文词频统计时，在提示词中将英文文本改为中文文本；若运行提示缺少分词模块，在集成终端执行 pip install 结巴（jieba）安装后重新运行。

- 历史教学材料；示例答案、数量、排名、界面和版本不能直接用于当前题目。
