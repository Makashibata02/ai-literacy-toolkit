# 智谱清言创建智能体

ID: `vid-3208a135358a8ea7` · 类型：历史来源 · 审核：`machine_reviewed`

本视频演示在智谱清言中创建可定制界面的智能体。智谱清言含智能问答、内容写作、AI 搜索与创建智能体；智能体是基于大模型、能完成某一方面任务的 AI 应用，用户可自行创建。在智谱清言左下角点「创建智能体」进入配置界面设定核心功能。该平台支持界面定制，可添加分类、单行文本、下拉选项等 UI 组件；配置信息中用双层大括号包裹变量参数（如 K1、K2、K3），即可按用户选择动态生成内容，例如选择考试科目、输入题量、选择提醒类型后生成对应题目。

## 操作与核对

1. 在智谱清言左下角点击『创建智能体』，进入智能体配置界面。
2. 在配置界面的提示词框中输入提示词，设定该智能体的核心功能。
3. 在智能体配置中选择添加 UI 组件（如分类组件、单行文本组件、下拉选项组件）以定制交互界面。
4. 在配置信息中用双层大括号包裹变量参数（如 {{K1}}、{{K2}}、{{K3}}），实现按用户选择动态生成内容。

- 历史教学材料；示例答案、数量、排名、界面和版本不能直接用于当前题目。
