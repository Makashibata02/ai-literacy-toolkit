# 找国标7714认识filetype和site搜索语法

ID: `vid-188b5eaaca3fad94` · 类型：历史来源 · 审核：`machine_reviewed`

本视频通过查找国标 7714 的 PDF 全文，演示搜索引擎 filetype 与 site 语法。百度搜名称结果杂乱少PDF；加 "filetype:PDF" 限定为 PDF 文件，但多来自百度文库、下载受限；再加 "site:EDU.cn" 限定为教育网（高校网站），结果可直接下载。总结：filetype 限定文件格式（PDF、PPT、DOC、XLS），site 限定来源；语法与关键词间空格隔开，空格表并且关系。

## 操作与核对

1. 在百度搜索框输入"国标 7714"，回车查看搜索结果。
2. 在原关键词后加空格和 "filetype:PDF"，限定检索结果为 PDF 文件。
3. 在检索表达式末尾加空格并追加 site:EDU.cn，把结果来源限定在教育网（如高校网站）。
4. 点击来自教育网、带 [PDF] 标记的结果，下载国标 7714 的 PDF 全文。
