# 高校信息素养教育数据库使用指南

ID: `vid-f099b4f7dd9e6884` · 类型：历史来源 · 审核：`machine_reviewed`

本视频介绍聚焦信息素养教育的综合资源平台高校信息素养教育数据库，以微视频为主，含专家讲座、习题、PPT，每视频配针对性练习题，适合碎片化学习。可搜索关键词或用九大类导航查找；浏览无需登录，做题与查看记录需注册。注册经平台统一身份认证，支持账号或 CARSI 登录，校外账号有效期 90 天。手机端可输网址或微信扫码进入。以库内“认识专利公布公告系统”为例，说明中国专利公布公告系统免费、权威、可查专利授权与公布。

## 操作与核对

1. 在浏览器登录高校信息素养教育数据库网址，系统按 IP 自动识别所在学校后可在库内浏览微视频。
2. 在数据库搜索框输入关键词并回车，从结果中点击播放；或通过首页九大类导航逐级查找视频。
3. 点击首页右上角“登录”，跳转平台统一身份认证页，有账号直接登录，无账号点“还没有账号前去注册”。
4. 注册时输入学校名称（或关键词选择学校）、姓名、手机号、密码及图形验证码、短信验证码后提交。
5. 首次登录需验证：识别到校园网 IP 自动通过，否则输入机构码验证；若学校为 CARSI 会员也可用 CARSI 认证登录。
6. 校外访问使用已注册账号登录，账号校外有效期限 90 天，过期须回校园网内登录一次。
7. 手机访问可在浏览器输入网址，或用微信扫描二维码进入手机版。

- 历史教学材料；示例答案、数量、排名、界面和版本不能直接用于当前题目。
