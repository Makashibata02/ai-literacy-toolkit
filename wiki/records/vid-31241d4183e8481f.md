# 清言PPT生成AIPPT

ID: `vid-31241d4183e8481f` · 类型：历史来源 · 审核：`machine_reviewed`

本视频演示用智谱清言旗下 AI 智能体「清言PPT」生成 PPT。首页可在对话框输入提示词生成，也提供「快速创建」三种方式：粘贴文本（最多两万字）、上传文件（PDF、DOC 等）、从 URL 导入（系统先提取网页内容再生成）。视频以国家网信办《提升全民数字素养与技能行动纲要》网页为例，从 URL 导入后选内容格式、输入要求、生成大纲，再选模板生成。生成后可编辑或下载，制作免费，下载可能需充值但一般每天有免费次数。

## 操作与核对

1. 在清言PPT 首页下方对话框中输入提示词，由系统按指令生成 PPT。
2. 在清言PPT『快速创建』中选择『粘贴文本』，根据笔记或已有内容（最多两万字）创建 PPT。
3. 在『快速创建』中选择『上传文件』，上传 PDF、DOC 等格式文件创建 PPT。
4. 在『快速创建』中选择『从 URL 导入』，输入网页网址，系统提取内容后创建 PPT。
5. 从 URL 导入后选择内容格式（如通用）并输入其他要求，点击『生成大纲』，再点击『生成 PPT』选择模板生成。
6. 生成完成后可点击编辑按钮修改，或点击『下载 PPT』按钮下载到本地。
