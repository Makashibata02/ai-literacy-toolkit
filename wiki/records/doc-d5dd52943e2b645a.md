# 知识模块46：文献管理工具

ID: `doc-d5dd52943e2b645a` · 类型：历史来源 · 审核：`machine_reviewed`

本模块梳理常用的文献管理工具及其功能。需要了解的工具包括 Mendeley、Zotero、知网研学 E-study、EndNote 和 NoteExpress，其中后两个明确不作命题。Mendeley 与 Zotero 是免费工具，既有网页版也有客户端；知网研学 E-study 可在 x.cnki.net 页面下载体验。样题涉及两个细节：Mendeley 网页版或客户端都可以通过 DOI 搜索添加文献，入口是 add new 中的 Add entry manually；知网研学桌面端添加中外文文献有四种方式，即内置数据库、DOI、常用学术搜索网站检索、导入第三方题录或本地上传。

## 操作与核对

1. 安装 Mendeley 或 Zotero 的客户端，也可使用其网页版，逐项体验题录管理与添加文献等功能。
2. 在 Mendeley 网页版或客户端点击 add new 按钮，选择 Add entry manually，按提示用 DOI 搜索并添加文献。
3. 在 x.cnki.net 的下载页面获取并安装知网研学 E-study，了解如何将参考文献导入文献管理软件。
4. 在知网研学桌面端分别尝试通过内置数据库、DOI、常用学术搜索网站检索以及导入第三方题录或本地上传这四种方式添加文献。
5. 确认其余文献管理工具中哪些属于免费工具。

- 历史教学材料；示例答案、数量、排名、界面和版本不能直接用于当前题目。
