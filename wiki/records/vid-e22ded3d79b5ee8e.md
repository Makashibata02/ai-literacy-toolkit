# mendeley：免费的文献管理工具

ID: `vid-e22ded3d79b5ee8e` · 类型：历史来源 · 审核：`draft`

本视频介绍免费文献管理工具 Mendeley，功能与 EndNote 相当但免费，最初由德国团队开发、现被爱思唯尔（Elsevier）收购，可长期信赖。它提供在线版与客户端：在线版登录官网即用，可注册账号、在 Library 建文件夹分类、拖拽 PDF 上传、用内置阅读器标记和做笔记；本地客户端功能更全。适合需管理文献但不愿或无法购买付费软件的用户。

## 操作与核对

1. 在浏览器登录 Mendeley 官网，点击“创建免费账号”按钮注册账号。
2. 用注册账号登录，在界面中选择 Library（文献库）。
3. 点击“创建文件夹”按钮，新建如“毕业论文”“创业大赛”等分类文件夹。
4. 打开文件夹，将电脑上的 PDF 文献用鼠标拖入窗口完成上传。
5. 上传后双击文献用内置 PDF 阅读器打开，可使用标记功能和在线笔记；右侧栏查看题录信息。

- 历史教学材料；示例答案、数量、排名、界面和版本不能直接用于当前题目。
