# 参考文献著录格式与题录导出

ID: `task-reference-export` · 类型：操作卡 · 审核：`machine_reviewed`

确认题目指定的格式及版本，或查看目标期刊的投稿要求。；在数据库选中文献，打开题录导出并查看实际支持的格式。

官方入口：[https://www.cnki.net/](https://www.cnki.net/)

## 输入条件

从题干提取平台、对象、字段、时间、类型、排序指标及需要比较的选项文字。

## 操作与核对

1. 确认题目指定的格式及版本，或查看目标期刊的投稿要求。
2. 在数据库选中文献，打开题录导出并查看实际支持的格式。
3. 核对文献类型、作者、年份、页码与标识符。
4. 不把教学材料中的格式版本当作所有平台已支持的证明。

- 按题目要求选定版本；导出后仍需逐项检查。
