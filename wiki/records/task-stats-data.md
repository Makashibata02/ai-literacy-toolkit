# 国家统计局 数据查询与指标口径

ID: `task-stats-data` · 类型：操作卡 · 审核：`machine_reviewed`

选择题目指定的数据来源和数据频率，按指标关键词查询。；核对指标名称、时间范围、地区和计量单位。

官方入口：[https://data.stats.gov.cn/](https://data.stats.gov.cn/)

## 输入条件

从题干提取平台、对象、字段、时间、类型、排序指标及需要比较的选项文字。

## 操作与核对

1. 选择题目指定的数据来源和数据频率，按指标关键词查询。
2. 核对指标名称、时间范围、地区和计量单位。
3. 在表格或图表中读取当前数据；不要沿用历史视频里的年份范围或数量。
4. 若下载需要登录，等待用户完成登录，再按页面可用格式导出。

- 原视频笔记的示例答案存在冲突，本卡仅保留查询方法。
- 注意累计值、当期值、单位与数据修订日期。
