豆包marscode

本视频介绍 AI 驱动云端 IDE 豆包 Mars Code，无需安装，登录网站即可在线编程，也可作 VS Code、JetBrains 插件。云端版登录后点“新建项目”，可从 Git 导入或从 Python、Node.js、Go、HTML、C++ 等模板创建。对话框输入自然语言提示词，系统即生成代码并给思路，代码可加入工作区运行调试。演示用提示词生成“求最近质数”程序，并修正“存在两个最近质数”的逻辑。

操作路径

  1. 在浏览器输入豆包 Mars Code 官网网址，进入官网首页。
  2. 点击“登录并获取编程助手”按钮，按提示登录后进入 IDE 界面。
  3. 点击左上角“新建项目”按钮，选择从模板创建，挑选 Python 等编程语言模板。
  4. 输入项目名称和描述后点击创建，进入工作界面。
  5. 在右侧对话框输入提示词（如“让用户输入一个数，程序给出最近的质数”），系统生成代码。
  6. 点击代码右上角“Add file”将代码加入工作区，点击“Run”按钮运行并输入测试数据。
